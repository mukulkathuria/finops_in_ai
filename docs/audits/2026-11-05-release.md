# Release audit (Phase 6, spec section 12 step 7), 2026-11-05

Scope: the whole gateway at `main`. Method:
- two independent reviewers over auth, budgets, cache and tenancy;
- the CI evidence of this phase: load, race and failure profiles, the restore drill, the latency
  bench, and the license check;
- a review of hot queries, configuration and the database.

Every finding below was verified against the code before it was fixed or accepted. A fix
carries the regression test that fails without it.

**Verdict:**
- No open Critical or High finding.
- One High and eleven Medium or Low findings are fixed.
- Three findings are accepted: A-M3, A-P1 and B-L2.
- Two fixes leave a documented residual: A-M1 and B-M5.
- The accepted risks and residuals are in section 7 and in `docs/threat-model.md`.

## 1. Two-reviewer cross-check

The two reviewers worked separately over the same four areas:
- **A**, an attacker's lens: bypass, forgery, cross-tenant reads, cache leaks;
- **B**, correctness under concurrency and failure: races, transactions, lock order, partial
  failures.

Both raised the billing finding (H1), each from its own side.

| Id | Lens | Finding | Disposition | Regression test |
| --- | --- | --- | --- | --- |
| H1 | B (and A) | A client that disconnected during a non-streaming provider call released its hold and left a zero-cost ledger row, while the provider answered and billed. Repeating it spent past every budget | Fixed in `ac75730`: whole-response calls run on, shielded, and are charged what the provider reports; a stream being opened is stopped and charged its estimated prompt | `test_release_review.py` (two tests) |
| A-M1 | A | Without provider usage, streams were estimated at 4 characters a token, undercounting Chinese text four to six times | Fixed in `ac75730`: half a token is added for each extra UTF-8 byte; ASCII text is counted as before. Residual in section 7 | `test_release_review.py::test_estimates_do_not_undercount_text_outside_ascii` |
| A-M2 | A | SSO login CSRF: the state was not bound to the browser that started the sign-in, so an attacker's callback or one-time code signed a victim into the attacker's account | Fixed in `355cc90`: a browser secret in an HttpOnly, SameSite=Lax cookie is hashed into both the state and the code | `test_us27_sso.py::test_us27_a_sign_in_completes_only_in_the_browser_that_started_it` |
| A-P2 | A | An empty `allowed_domains` linked any email the provider called verified | Fixed in `355cc90`: naming no domain links nothing | `tests/unit/test_sso.py` |
| A-P3 | A | The RLS audit inspected only `tenant_isolation`, while permissive policies are OR-ed | Fixed in `cf4bac2`: every other policy must be a hash lookup or the worker's | `test_schema_rls.py::test_rls_audit_flags_a_policy_that_widens_access`, `tests/unit/test_audit_rls.py` |
| A-L1 | A | An Idempotency-Key did not commit to the team a request is charged to | Fixed in `60449eb`: the team is part of the key's request fingerprint | None dedicated. The idempotency suites still pass |
| B-M1 | B | A timezone change committed before the counters were rebuilt, so reservations could start a new period at zero | Fixed in `66de7ae`: the rebuild runs in the settings transaction, in the counters' lock order | Existing timezone rebuild tests (D-12) |
| B-M2 | B | Two permanent grants approved at once read the same limit; one increase was lost | Fixed in `66de7ae`: the team cap's lock, then the budget row `FOR UPDATE`, then a fresh read. Same order as a limit change, so no deadlock | `test_us08_member_limits.py::test_two_permanent_grants_approved_at_once_both_count` |
| B-M3 | B | A stream could outlive its 15-minute hold: the janitor returned the budget mid-stream and a retry could take its Idempotency-Key | Fixed in `60449eb`: a stream ends after 12 minutes with `finish_reason: "length"` | `test_relay.py::test_a_stream_ends_as_if_at_max_tokens_before_its_hold_can_expire` |
| B-M4 | B | A logout racing a rotation revoked the family with a snapshot that missed the new token | Fixed in `e3639d7`: one change per family at a time (an advisory lock), and refresh reads its token again | `test_us03_sessions.py::test_a_logout_during_a_rotation_also_revokes_the_rotated_token` |
| B-M5 | B | When the ledger could not be written after the provider answered, the client got a 500 and retried (paying twice), and the charge was recorded nowhere | Fixed in `60449eb`: the answer is returned and the unrecorded charge is logged with its numbers. Residual in section 7 | `test_release_review.py::test_m5_an_answer_whose_settlement_fails_still_reaches_the_client` |
| B-L1 | B | The `worker` role could insert into and update `budgets` and `budget_requests`, which it never needs | Fixed in `cf4bac2` (migration 0029) | `test_schema_rls.py::test_the_worker_reads_budgets_but_cannot_change_them` |
| A-M3 | A | Data-plane authentication costs a lookup per well-formed API key, before any throttle | Accepted (section 7) | — |
| A-P1 | A | DNS rebinding against admin-configured URLs (the SSO issuer, the webhook) | Accepted (section 7) | — |
| B-L2 | B | If a commit acknowledgement is lost, a retried `_begin` meets its own claim and the stray hold waits 15 minutes | Accepted: rare, and the janitor recovers it | — |

Confirmed sound by both reviewers:
- reservations cannot admit `committed + reserved` above a limit;
- every budget path locks counters in ascending id order;
- settlement is idempotent per hold;
- cache keys cover org, team, user, every parameter, the policy and the rules version, and
  sealed answers are bound to org and key;
- tenant context is transaction-local, and lookup policies expose one row;
- JWT `alg` and `kid` are pinned and status and roles are re-read on every request;
- API keys have no cache, so revocation is immediate;
- the OIDC ID-token checks hold.

## 4. Hot queries

Every statement on the request path is an equality lookup on a unique key or a primary key, or
an index range bounded by org and time. None scans a table.

| Statement (stage) | Access path |
| --- | --- |
| API key by digest (`auth`) | `api_keys.key_hash` UNIQUE |
| Refresh token by digest | `refresh_tokens.token_hash` UNIQUE |

## 5. Configuration and database review

Configuration:
- Production-like environments refuse placeholder secrets and URLs, and an unset `ENVIRONMENT`
  means production (`tests/unit/test_foundations.py`).
- `PUBLIC_BASE_URL` must be https there; the SSO cookie is then https-only.
- `.env.example` reads the same under compose and python-dotenv for all 97 settings.
- `/metrics` needs `METRICS_TOKEN` outside dev and test.
- There is no CORS: the dashboard reaches `/v1` through its own origin.

Database:
- `migrator` owns every table and the public schema, and has no BYPASSRLS. Only it can
  create objects (`infra/docker/postgres/sql/database-setup.sql` revokes the schema from
  PUBLIC).
- `app` and `worker` hold only the privileges each table grants them, and the worker no longer
  writes budgets (migration 0029).
- `readonly_analytics` reads under RLS.
- Every connection sets `statement_timeout` (5 s), `lock_timeout` (3 s) and
  `idle_in_transaction_session_timeout`, and pools are bounded (20 + 10 per process; PostgreSQL
  allows 300).
- Forced RLS on every tenant table, with the audit in CI.

Backups and restore:
- `scripts/restore_drill.sh` restores a dump into a new database made as `restore.md` makes one.
- It proves the copy identical: schema, grants, row security, policies, sequences, every
  table's rows by count and content hash, and the ledger totals per org.
- CI runs it on every push. The `load` workflow runs it on the database the profiles filled:
  96 tables and 32,042 rows identical at `cb1349d`.

Licenses: 97 gateway, 53 docparse and 3 dashboard packages. Nothing is copyleft but five weak
copyleft libraries used unmodified (psycopg LGPL-3.0, certifi, orjson's part and tqdm under
MPL-2.0), approved in `scripts/check_licenses.py`.

## 6. Load profiles (section 11)

The `load` workflow ran on one shared 4-vCPU runner, with every service and k6 sharing it. The
mock provider answered in a fixed 50 ms. At `643a8f7`:

| Profile | Result |
| --- | --- |
| Spike, 18 to 90 requests a second, then 60 | Pass: no errors. Once recovered, overhead p95 72 ms, p99 80 ms |
| Budget race, 500 requests at once on a 560-token budget | Pass: only 200 or 429 `budget_exceeded`; committed 480 of 560, nothing left reserved |
| Failure under load, PostgreSQL restarted a minute in | Pass: two minutes later, overhead p95 69 ms, p99 74 ms, and no errors |
| Restore drill on the filled database | Pass: 96 tables and 102,381 rows identical |
| Baseline, 100 users with a second's think time (about 75 requests a second) | **Not met:** no errors, but overhead p95 352 ms and p99 519 ms |

The baseline's diagnosis, from the run's per-stage times and container CPU:
- Its minimum overhead, 62 ms, was two mock sleeps counted as gateway time: the injection
  classifier answered in the provider's 50 ms, and the embedding in 10 ms.
- The gateway container used 95% of a CPU halfway through. Its first process held about
  two-thirds of the keep-alive connections, so that process saturated.
- Every request wrote about six INFO log lines: httpx's per-call lines, a decision for every
  guardrail that passed, and the access line.

In progress: the classifier mock now answers in a classifier's 10 ms; passed guardrail decisions
log at DEBUG (the metric still counts them); httpx's lines are quiet outside DEBUG. The spike's
recovered phase already meets the SLO at 60 requests a second. The `load` workflow re-measures
the baseline on every change to the profiles.

## 7. Residual and accepted risks

| Risk | Why accepted | Upgrade path |
| --- | --- | --- |
| A-M3: an unauthenticated flood of well-formed API keys costs one indexed lookup each | A per-IP block inside the gateway would also block legitimate callers behind a shared proxy; JWTs are verified before any database access | Rate-limit unauthenticated traffic at the ingress or WAF |
| A-P1: DNS rebinding between the public-address check and the connection, for URLs an org admin sets | A privileged actor, and only a blind request; redirects are off and answers are size-capped | Deny private, link-local and metadata ranges with egress network policy; or pin the checked address in the HTTP transport |
| B-M5 residual: a charge whose ledger write fails (the database unreachable through three attempts) is logged, not spooled | Bounded to requests in flight during an outage; the log carries org, team, model, cost, tokens and images | A durable spool (local file or queue) replayed by the worker |
| Token estimates when a provider reports nothing (cancelled streams) | Within about 2x for any script now, and bounded by the hold | Count with the provider's tokenizer where one is published |
| PostgreSQL 19 GA not released | External: GA planned 2026-11-19 | `docs/runbooks/postgres-upgrade.md`; re-run CI, bench and load on GA |
| MFA for admins not enforced | v1 scope (threat model) | TOTP for ORG_MANAGE |
